# 顏色調調樂

擠顏料、調顏色的小遊戲。小變色龍「彩彩」想畫橘子、葡萄、櫻花、夜空……小朋友要點顏料管把顏料擠到調色盤上，按「攪一攪」，看看能不能調出彩彩要的顏色。調對了，圖會塗上顏色，彩彩也會變成那個顏色！

**整個遊戲只有一個 `index.html` 檔案，不用網路、不用安裝、不用註冊，也不會蒐集任何個人資料。** 特別適合網路不穩或設備有限的偏鄉教室。

## 線上使用

👉 https://je5577iee.github.io/color-mix/

## 離線使用（沒有網路的教室）

1. 在有網路的地方下載本專案的 `index.html`（點進檔案 → 右上角「Download raw file」）
2. 用隨身碟複製到教室的電腦或平板
3. 點兩下用瀏覽器打開就能玩，完全不需要網路

## 玩法

選好難度後按「開始畫畫！」，一回要調 8 種顏色。

1. 看彩彩想畫什麼、需要什麼顏色
2. 點顏料管，一次擠一滴到調色盤上（每種顏料最多 4 滴）
3. 按「攪一攪」，顏料會轉一轉混在一起，變出新的顏色
4. 擠錯了可以按「倒掉重來」

### 三種難度

| 難度 | 顏料 | 要調的顏色 |
|---|---|---|
| 簡單 | 紅、黃、藍 | 橘色、綠色、紫色 |
| 進階 | 紅、黃、藍、白、黑 | 粉紅色、淺藍色、灰色、深藍色（加白變淺、加黑變深） |
| 困難 | 紅、黃、藍、白、黑 | 黃綠色、橘黃色（要多一點、少一點）、咖啡色、淺紫色、淺綠色（三種顏色） |

比例一樣就算對，例如黃 2 滴＋藍 1 滴，跟黃 4 滴＋藍 2 滴都是黃綠色。

每次玩，要畫的東西都是隨機的，**同一回的 8 張圖不會重複**（簡單模式有橘子、南瓜、紅蘿蔔、籃球、葉子、荷葉、小黃瓜、葡萄、茄子 9 種可以抽）。

## 提示與鼓勵

- **調錯第一次會出現提示，可以再試一次**；第二次才調對算一半
- 簡單：出現**色環**，看看橘色在哪兩個顏色的中間
- 進階：出現「加白色變淺 ← 原來的顏色 → 加黑色變深」的色條
- 困難：提醒「黃色要多一點」、「要用到三種顏色」、「先調紫色再加白色」
- 第二次還調錯，會直接告訴小朋友要幾滴什麼顏色
- 調錯時不會出現傷心或責備的畫面，只有鼓勵的話

## 其他功能

- **注音開關**：首頁可以打開注音，採用國語課本的直式注音
- **音效開關**：音效由瀏覽器即時產生，不需要音檔
- 每個難度的最佳成績會以星星顯示（只存在這台裝置）
- 支援電腦、平板、手機

## 適用對象與教學建議

- **適用**：國小學生認識顏色、三原色與混色，可搭配美勞課
- **課堂示範**：投影遊戲，先讓學生猜「紅色加藍色會變什麼？」，再按攪一攪揭曉
- **動手做**：玩完後拿真的水彩，照著遊戲的配方調調看，比較跟螢幕上的顏色像不像
- **觀察規律**：引導學生發現「加白色會變淺、加黑色會變深」

## 關於顏色

遊戲裡的混色是模仿**顏料**（紅黃藍）的調色方式畫出來的，所以紅加黃會變橘色、黃加藍會變綠色。真的水彩會因為品牌、水量不同而有一點差別，這是正常的。

## 注意事項

- 最佳成績只存在**那台裝置的瀏覽器**裡，換裝置或清除瀏覽器資料就會消失
- 注音經過人工檢查，若發現讀音有誤，歡迎提出 Issue 告訴我們
